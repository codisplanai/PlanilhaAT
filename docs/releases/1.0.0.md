# PlanilhaAT 1.0.0

Primeira release de produção do fluxo containerizado oficial.

## Destaques

- Aplicação FastAPI + React distribuída como uma única imagem OCI.
- PWA nativo com manifest, service worker, instalação standalone e fallback offline.
- Imagem da aplicação publicada no GHCR com tags SemVer e referência imutável por digest.
- Bases Node e Python mantidas em pacotes GHCR próprios do projeto.
- Imagem PostgreSQL local opcional mantida no GHCR do projeto.
- Compose compatível com Docker Compose, Portainer e Dockge.
- CloudPanel utilizado apenas para domínio, TLS e reverse proxy para a porta local da aplicação.
- Alembic executado automaticamente no startup do container e disponível também como serviço manual `migrate`.
- SBOM e provenance attestation habilitados no build de release.
- Healthcheck obrigatório antes da criação da Git tag e GitHub Release.
- Limpeza automática de caches e imagens efêmeras sem apagar releases SemVer utilizadas para rollback.

## Segurança de deployment

- A porta da aplicação fica vinculada a `127.0.0.1` por padrão.
- O container executa como usuário não-root.
- `no-new-privileges` e `cap_drop: ALL` são aplicados ao container da aplicação.
- O filesystem principal da aplicação é read-only, com escrita apenas nos volumes de storage e `/tmp`.
- Segredos de produção permanecem exclusivamente no `.env` do host/stack manager e não são incorporados à imagem.
